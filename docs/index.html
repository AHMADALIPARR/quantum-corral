Quantum Corral

Electron density |ψ|2 inside a circular hard-wall corral, computed by the quantum-corral Fortran simulator and its Bessel eigenmode model. The field on load is the simulator's own output — move the controls and the page recomputes the same model in your browser.

Drag to rotate. Height is Z = 0.55·ρnorm + 0.85·Vnorm (the repo's MATLAB surface formula); the 48 rim spikes are the atomic ring potential.

Data source & tests

Default field: Fortran corral_sim eigen run, built with gfortran and executed — not read off any documentation.

./corral_sim --mode eigen --a1 0.99 --a2 0.81 --phase 190 --n 256

The in-page Bessel model (J0/J1 by power series) was checked against the full 10,404-point Fortran grid: max difference 1.187e-6, the rounding level of the stored data. make test in the repo: 3 PASS.

  • PASSABI layout & stride round-trip verification
  • PASSCross-stack density match max|tinyAPL − MATLAB| = 0, max|tinyAPL − Vulkan| = 9.943e-08
  • PASSTDSE probability conservation P0 = 0.609359, rel drift = 9.396e-07
What this is: an ideal hard-wall continuum model in dimensionless units (R = m* = ℏ = 1). It is not a calibrated Cu(111)/Fe-adatom surface-state corral — no material parameters, no STM tip model, no measured data.
Source code and simulator: github.com/AHMADALIPARR/quantum-corral. 2D view uses the repo's cyan corral colormap; rim dots are the 48 atoms in gold rgb(0.92, 0.76, 0.45).
